  • The Saint Jimmy Formula Sheet (2026 - present) - This was put together by me throughout college and is designed to be a comprehensive reference of math formulas that are relevant in high school and college level mathmatics.
  • OSU Cybersecurity Club Honeymonkey (2026) - I wrote the skeleton for one of OSU Cyber Security Club's backend utilities. It is written in Python 3.14 and makes use of various technologies, including the JSON specification, python pip, SHA-256 hashing, and the Selenium WebDriver (used for exploring and interacting with websites). This honeymonkey runs through the CTF (capture the flag) website to complete cyber security challenges, check hashes of files to make sure they aren't corrupted, and report when any of that fails.
  • Update Discord Script (2024) - This is a 5-line bash script that updates discord to the lastest .deb version on Debian-based linux distros. The distrobution of Discord for debian does not update itself for some reason and will refuse to launch if it is not the latest version, so I made this script so that I don't need to manually write out the shell commands. You could modify your discord .desktop file to run this script before trying to launch discord, or just run the script on a sucessful login to the computer.
  • Miitopia Randomizer (2023, revised 2025) - This is my fork of the Miitopia randomizer project. It heavily utilizes Python 3 and required parsing .sarc files, rudamentary spreadsheet files, and a bit of reverse-engineering. Miitopia is a simple RPG game where you fight enemies, recruit teammates, and defeat a big bad guy. My fork expands on the original randomizer's capabilities by randomizing Inn rooms, preventing some weird crashes on the 3DS port of the game, rebalancing a few enemies, limiting music randomization, and cleaning up the pre-existing code.
